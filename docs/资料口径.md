# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

按费用line_id核对责任，service_date决定计划资格。plans的priority小者先承接；base为eligible费用减已有优先计划确认责任，不减未审申请；rate×base受同benefit_pool年度剩余额限制。household共享池。adjudications的approved为确认责任占池，pending不占已用但单列保留；reserved由明确reservation单列，不能当approved。已确认责任以confirmed_at顺序占用，后来旧费申请不倒挤；revoked只释放所引用的原裁定，后续新分配需明确确认，不静默重排所有历史。费用下修导致原责任超基数时保留差额待核，不删实收。personal cash保留真实收退款，责任减少只是应退不自动生成退款。payment可分多裁定，到账与责任不重复。所有规则为合成内部合同，不代表医保政策。

## members

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| person | string | 人 |
| household | string | 家庭 |

同一来源记录键的新文件表示整行修订，调用者明确接收次序；原始文件和接收历史须保留。相同文件摘要不增加事实。下面标为后续接收的文件不随基础资料自动生效，用户可分次装载。历史事实的业务时点与本次接收时点分开。金额除另述外人民币元，结算舍入到分的尾差归该账单分摊基数最大项，并列按业务键升序。本文规定来源语义，不规定待开发仓表、算法或架构。

enrollments未声明某plan时该人无资格，P2没有PRIMARY。同household同benefit_pool同自然年共享限额。approved小于合同理论值也可为裁定事实，差异可查不覆盖裁定；AD4对B项目EXTRA不适用，必须待核。pending默认不预占，若使用reservation需独立原始记录明确保留量和期限。收入责任、待审和现金不合并。
